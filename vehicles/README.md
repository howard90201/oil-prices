# 車型資料（車帳本「新增車輛」用）

每月自動檢查 Yahoo汽車機車有沒有新車款，整理成待確認清單；確認後才套用到主檔。

## 流程
1. **每月 1 日 03:17（台北）**：`車型資料每月檢查` 讀 Yahoo 網站地圖，找出還沒讀過的車款頁，讀規格、照既有規則轉成主檔格式，寫成 `pending/<日期>.csv` 和說明 `pending/<日期>.md`，並開一個「車型資料待確認」issue。政府新審驗車型（環境部噪音審驗、能源署耗能證明）也一起列出來對照，不會自動加進主檔。
2. **確認**：看 issue 和清單。不要的列把 `action` 改成「不要」。
3. **套用**：在 issue 加上「同意套用」標籤（或手動執行 `車型資料套用`），`apply.py` 會更新主檔和 `data/vehicles.json`，然後關閉 issue。
4. **車帳本**：每週一的「車帳本牌價每週同步」會一併檢查 `data/vehicles.json`，有變就換掉車帳本裡的車款資料。

## 檔案
- `data/taiwan_vehicle_models.csv`：主檔（欄位說明見專案文件「車型資料庫說明.md」）
- `data/vehicles.json`：車帳本用的車款資料，由主檔產生
- `data/yahoo_seen.txt`：已經讀過的 Yahoo 車款頁
- `data/rules.json`：Yahoo 代號對品牌、品牌中英文名
- `data/gov_state.json`：已經看過的能源署檔案
- `scripts/monthly.py`、`scripts/apply.py`、`scripts/common.py`

## 沿用的規則（2026-10-30、11-18 定案）
年式以 Yahoo 為準；油電車用系統總合馬力；連續年份規格相同就合成一筆；有「滿電可續航里程」或車名有 PHEV 等字的油電車標成插電式複合動力；電動車記電池度數與可用度數。新車型、新品牌、缺馬力或油箱的會標在「需要確認」。
