油耗保養 APP 使用的油價資料，每週一凌晨自動更新並累積。

## 檔案

- `data/oil_prices.csv`：油價資料。欄位：品牌、油品、每公升價格、生效時間（台北時間）、與上次差額、來源、狀態。
- `scripts/update_oil_prices.py`：更新程式。
- `.github/workflows/update.yml`：自動執行設定，每週一 02:00（台北時間）。

## 查價規則

找某次加油的單價：取同品牌、同油品中，生效時間早於或等於加油時間的最新一筆。

## 狀態

- 已確認：正常價格。
- 待確認：單次漲跌達 3 元以上，照樣記錄，但建議人工核對。

實際售價以各加油站公告為準。好市多、能源署資料為非官方擷取，介面可能變更。
